# Portfólio — Lucas da Silva Trindade

Site pessoal publicado em **[lucastrindadedev.com.br](https://lucastrindadedev.com.br)**.

- Página única em `index.html`, sem dependências externas nem build.
- Três idiomas (PT, EN, ES) e tema claro/escuro, com a escolha salva no navegador.
- Durações e totais calculados em tempo real.
- Botão **Baixar currículo (PDF)** gera o currículo na hora a partir dos mesmos dados do site, no idioma selecionado.

## Como atualizar

Todo o conteúdo fica nas constantes no topo do `<script>` do `index.html`
(`PROFILE`, `JOBS`, `STACKS`, `EDUCATION`, `COURSES`, `UDEMY`, `BOOKS`, `LANGUAGES` etc.).
Alterou os dados, fez `git push`: site e currículo saem atualizados.
